# 🎓 Study Group Application

A collaborative study group application with real-time features, AI assistance, and PDF collaboration capabilities.

## 🚀 Features

- **User Authentication & Management** - Secure user registration and profile management
- **Group Management** - Create and manage study groups with role-based permissions
- **Meeting Scheduling** - Schedule meetings with calendar integration
- **Real-time Communication** - Chat, voice/video calls, and screen sharing
- **PDF Collaboration** - Upload, annotate, and collaborate on PDF documents
- **AI Assistant** - Intelligent Q&A and document analysis using OpenAI
- **File Sharing** - Secure file upload and sharing within groups

## 🛠️ Tech Stack

### Backend
- **Node.js** with Express.js
- **MongoDB** for database
- **Redis** for caching and sessions
- **Socket.io** for real-time communication
- **JWT** for authentication
- **OpenAI API** for AI features

### Frontend
- **React** with TypeScript
- **Material-UI** for components
- **Socket.io-client** for real-time features
- **PDF.js** for PDF rendering
- **WebRTC** for video calls

## 📋 Prerequisites

- Node.js 18+
- MongoDB 6.0+
- Redis 6.0+
- Git

## 🚀 Quick Start

### Backend Setup
```bash
cd backend
npm install
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```
